What's the content of the head section?

This section is suppose to hold metadata of the HTML document instead of content for the page, the most common elements within this tag are:

  • title: Defines the title of the page, which is displayed in the browser's title tab or tab.
  • link: Used to link external resources like stylesheets (CSS) or favicons.
  • style: Used to define the internal CSS styles for the page.
  • script: Used to include Javascript code or link to the external Javascript files
